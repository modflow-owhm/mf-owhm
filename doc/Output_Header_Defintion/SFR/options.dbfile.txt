
SFR package OPTIONS block DBFILE output file

Writes for each time step every SFR reach's inflow, outflow, seepage, 
and the reach properties used to calculate them, in a database friendly
format (one row per reach and time step, the same columns for every row).
When transient routing is active (TRANSROUTE with IRTFLG > 0), the values
are from the last routing time step (NUMTIM) of the time step.

Without routing, every row satisfies the reach water balance:
   FLOW_OUT = FLOW_IN + RUNOFF + PRECIP - STREAM_ET - FLOW_SEEPAGE
With routing, the change in channel storage is also part of the balance
(see the STORAGE_CHANGE column of PRINT_TRANSROUTE).

The columns FLOW_WT and CHNG_UNSAT_STOR are only included when
unsaturated flow beneath the streams is simulated (ISFROPT 2 to 5).

The output may be text or binary format.

If the output file is text format, then it will contain a single header line
followed by the output written for each time step. If the output file is binary format,
then each time step writes a binary record for each reach containing only the output data.


/-------------------------------------\
|                                     |
|    Text File Header Definition      |
|                                     |
\-------------------------------------/

DATE_START                 is the starting calendar date of the time step in the form: yyyy-mm-ddThh:mm:ss
                              (NaN if the DIS package does not specify a STARTDATE)
PER                        is the stress period number
STP                        is the time step number
DELT              [T]      is the time step length
SIMTIME           [T]      is the simulated time at the end of the time step
SEG                        is the stream segment number
RCH                        is the reach number within the segment
FLOW_IN           [L3/T]   is the streamflow entering the reach (upstream reach outflow, or the segment inflow for the first reach)
FLOW_SEEPAGE      [L3/T]   is the seepage between the stream and the aquifer; positive is a losing stream (water leaves the stream), negative is a gaining stream (water enters the stream).
                              With unsaturated flow (ISFROPT 2 to 5) and the aquifer head below the streambed, this is the seepage into the unsaturated zone.
FLOW_OUT          [L3/T]   is the streamflow leaving the reach
RUNOFF            [L3/T]   is the overland runoff into the reach: the segment RUNOFF distributed by reach length plus the runoff from other packages (for example, FMP or UZF).
                              Negative values are withdrawals (for example, FMP semi-routed deliveries).
PRECIP            [L3/T]   is the precipitation falling on the stream surface (rate times the stream surface area)
STREAM_ET         [L3/T]   is the evapotranspiration from the stream surface (rate times the stream surface area)
HEAD_STREAM       [L]      is the stream stage (water surface elevation)
HEAD_AQUIFER      [L]      is the groundwater head of the model cell that contains the reach
DEPTH_STREAM      [L]      is the stream depth (HEAD_STREAM minus ELEV_UP_STREAM)
WIDTH_STREAM      [L]      is the stream width
LENGTH_STREAM     [L]      is the reach length
HEAD_GRADIENT     [L/L]    is the head gradient across the streambed: (HEAD_STREAM - max(HEAD_AQUIFER, streambed bottom)) / streambed thickness
COND_STREAM       [L2/T]   is the streambed conductance: K * WIDTH_STREAM * LENGTH_STREAM / streambed thickness
                              (K includes the LOSSFACTOR when the stream is losing)
ELEV_UP_STREAM    [L]      is the elevation of the top of the streambed
FLOW_WT           [L3/T]   is the flow through the unsaturated zone that reaches the water table   (only with ISFROPT 2 to 5)
CHNG_UNSAT_STOR   [L3/T]   is the change in water stored in the unsaturated zone beneath the reach (only with ISFROPT 2 to 5)

SEG                 INTEGER
RCH                 INTEGER
FLOW_IN             DOUBLE
FLOW_SEEPAGE        DOUBLE
FLOW_OUT            DOUBLE

PRECIP              DOUBLE
STREAM_ET           DOUBLE
HEAD_STREAM         DOUBLE
HEAD_AQUIFER        DOUBLE
DEPTH_STREAM        DOUBLE
WIDTH_STREAM        DOUBLE

/----------------------------\
|                            |
|   Additional Information   |
|                            |
\----------------------------/


Date output is formatted using ISO 8601-1:2019 standard without a time zone designation:
https://en.wikipedia.org/wiki/ISO_8601#Combined_date_and_time_representations

The general format is:
yyyy-mm-ddThh:mm:ss
                   where:
                         yyyy is the four digit Gregorian year
                         mm   before the T is the two digit month number       (01 to 12)
                         dd   is the two digit day of the month                (01 to {28, 29, 30, 31}, depending on the month)
                         T    calendar date and 24-hour clock time separator
                         hh   is the hour within the day                       (00 to 23 hour)
                         mm   after the T is the two digit minutes in the hour (00 to 59 minute)
                         ss   is the two digit seconds of the minute           (00 to 59 second)

Output is in model units that uses an
   L as a place holder for Length, L2 is for area, L3 is for volume and
   T as a place holder for Time

which are defined in the DIS package as being:
   L: Feet, Meters, Centimeters, and Undefined
   T: Seconds, Minutes, Hours, Days, Years, and Undefined

------------------------------------------------------------------------------------------

The MODFLOW-OWHM standard binary formatting is set to
Fortran Unformatted Stream (C style binary).

The description of each header indicates the Fortran variable
that is used to write the binary recorded.

The following explain their storage use:

Keyword       Storage      Default Fortran Type  Python Numpy Type       Fortran 2003 Standard
DOUBLE        8 bytes      Double Precision      numpy.dtype('float64')  REAL(kind=real64)
INTEGER       4 bytes      Integer               numpy.dtype('int32')    INTEGER(kind=int32)
CHARACTER(X)  X × 1 bytes  Character(X)          numpy.dtype('SX')       CHARACTER(len=X)
SNGL          4 bytes      Real                  numpy.dtype('float32')  REAL(kind=real32)
